# 过程资料目录

本目录保存开发过程中的记录、草稿、旧版联调材料和辅助资料。课程组正式审阅时不需要逐一阅读本目录；最终交付文档以 `文档/交付文档目录.md` 中列出的文件为准。

## 1. 分类说明

| 子目录 | 内容 | 用途 |
|---|---|---|
| `01-项目管理/` | 阶段任务完成说明 | 追溯任务拆分与完成记录 |
| `02-联调对接/` | 前后端对接草稿、管理端/用户端联调细节 | 追溯开发联调过程 |
| `03-部署运维/` | 旧版本地启动、部署、数据库和测试账号说明 | 追溯部署方案演进 |
| `04-测试验收/` | 测试脚本、自动测试结果、测试报告过程文件 | 追溯测试执行过程 |
| `05-草稿旧稿/` | 后端改造草稿、查漏补缺、未核对实体表 | 保留草稿，不作为正式依据 |
| `06-协作资料/` | GitHub 使用手册和协作截图 | 小组协作过程材料 |
| `07-用户手册过程/` | 用户手册 PDF 修改清单 | 用户手册制作过程记录 |

## 2. 使用原则

- 本目录资料仅用于追溯，不作为最终接口、功能或部署依据。
- 如果过程资料中的内容与正式文档冲突，以正式文档为准。
- 新增过程资料应放入对应分类目录，不要直接堆放在 `过程/` 根层。

## 3. 正式文档入口

正式交付文档入口：

```text
文档/交付文档目录.md
```

项目唯一入口 README：

```text
README.md
```
