# 部署与运行说明

## 1. 项目组成与端口

| 服务 | 路径 | 默认地址 |
|---|---|---|
| 用户端前端 | `代码/前端/前端用户端` | `http://127.0.0.1:3000` |
| 管理端前端 | `代码/前端/前端管理端` | `http://127.0.0.1:3001` |
| Django 后端 | `代码/后端/后端代码` | `http://127.0.0.1:8000` |
| Django API | `代码/后端/后端代码` | `http://127.0.0.1:8000/api/` |
| AI HTTP 服务 | `代码/AI服务/AI服务器代码` | `http://127.0.0.1:8010` |
| AI 健康检查 | `代码/AI服务/AI服务器代码` | `http://127.0.0.1:8010/health` |
| AI 模型注册表 | `代码/AI服务/AI服务器代码` | `http://127.0.0.1:8010/api/v1/admin/model-registry` |

## 2. 环境要求

| 环境 | 建议版本 |
|---|---|
| Python | 3.11 或 3.12 |
| Django | 4.2 系列，由后端依赖文件安装 |
| Node.js | 20+ |
| Redis | 6+ 或 7+ |
| 数据库 | 本地联调用 sqlite；云端部署可使用 MySQL/MariaDB |

后端本地依赖文件：

```text
代码/后端/后端代码/requirements.local.txt
```

论文 PDF 预处理依赖 `PyMuPDF`，代码导入名为 `fitz`。

## 3. 推荐一键启动

在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-local-windows.ps1
```

停止服务：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/stop-local-windows.ps1
```

## 4. 手动启动步骤

### 4.1 后端环境

```powershell
cd 代码/后端/后端代码
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.local.txt
```

如果本机没有 `py` 启动器，可使用实际安装的 Python 可执行文件创建虚拟环境。

### 4.2 数据库迁移与测试账号

本地联调建议显式使用本地 settings，避免误连远端数据库：

```powershell
cd 代码/后端/后端代码
$env:DJANGO_SETTINGS_MODULE="fake_image_detector.local_settings"
$env:AI_SERVICE_URL="http://127.0.0.1:8010"
$env:AI_SERVICE_TIMEOUT_SECONDS="120"
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe scripts/init_test_users.py
```

本地 sqlite 默认位于：

```text
代码/后端/db.sqlite3
```

### 4.3 AI 服务

```powershell
cd 代码/AI服务/AI服务器代码
..\..\后端\后端代码\.venv\Scripts\python.exe train_minimal_baseline.py
..\..\后端\后端代码\.venv\Scripts\python.exe ai_http_service.py --host 127.0.0.1 --port 8010
```

检查：

```powershell
Invoke-RestMethod http://127.0.0.1:8010/health
Invoke-RestMethod http://127.0.0.1:8010/api/v1/admin/model-registry
```

### 4.4 Django 后端

```powershell
cd 代码/后端/后端代码
$env:DJANGO_SETTINGS_MODULE="fake_image_detector.local_settings"
$env:AI_SERVICE_URL="http://127.0.0.1:8010"
$env:AI_SERVICE_TIMEOUT_SECONDS="120"
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

### 4.5 用户端前端

```powershell
cd 代码/前端/前端用户端
npm install
npm run dev -- --host 127.0.0.1 --port 3000 --strictPort
```

前端 `.env` 建议设置：

```text
VITE_API_URL=http://127.0.0.1:8000
```

### 4.6 管理端前端

```powershell
cd 代码/前端/前端管理端
npm install
npm run dev -- --host 127.0.0.1 --port 3001 --strictPort
```

前端 `.env` 同样建议设置：

```text
VITE_API_URL=http://127.0.0.1:8000
```

## 7. 手动停止

如果服务在前台窗口运行，直接在对应窗口按 `Ctrl+C`。

如需按端口强制停止：

```powershell
foreach ($port in 3000,3001,8000,8010) {
    Get-NetTCPConnection -LocalPort $port -State Listen -ErrorAction SilentlyContinue |
        Select-Object -ExpandProperty OwningProcess -Unique |
        ForEach-Object { taskkill /PID $_ /T /F }
}
```

## 8. 常见问题

### 8.1 后端误连远端数据库

请确认启动后端前设置：

```powershell
$env:DJANGO_SETTINGS_MODULE="fake_image_detector.local_settings"
```

### 8.2 AI 服务不可用

先检查健康接口：

```powershell
Invoke-RestMethod http://127.0.0.1:8010/health
```

再确认后端环境变量：

```powershell
$env:AI_SERVICE_URL="http://127.0.0.1:8010"
$env:AI_SERVICE_TIMEOUT_SECONDS="120"
```

### 8.3 PDF 上传时报 `No module named 'fitz'`

重新安装后端依赖：

```powershell
cd 代码/后端/后端代码
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.local.txt
```

### 8.4 账号无法登录

重新执行测试账号同步脚本：

```powershell
cd 代码/后端/后端代码
$env:DJANGO_SETTINGS_MODULE="fake_image_detector.local_settings"
.\.venv\Scripts\python.exe scripts/init_test_users.py
```

## 9. 文件格式限制

| 功能 | 支持输入 | 说明 |
|---|---|---|
| 图像检测 | PNG、JPG、PDF 提取图片、压缩包内图片 | PDF 可用于提取图片进入图像检测 |
| 论文检测 | `.pdf` | 后端提取文本、清洗、分段并生成 AI 输入 |
| Review 检测 | 在线文本、`.txt` | 后端做编码和文本清洗 |
| 人工审核 | 已有检测任务或检测结果 | 发布者申请，管理员审批，审稿人复核 |
