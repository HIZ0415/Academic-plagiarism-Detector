# 课程组交付文档总览

本文档是课程组审阅本项目的入口。

## 1. 推荐阅读顺序

课程组审阅建议只阅读以下 5 类文档：

| 顺序 | 文档 | 说明 |
|---|---|---|
| 1 | `../README.md` | 项目概览、模块结构、启动入口 |
| 2 | `平台功能与设计说明.md` | 平台功能、角色、业务流程、系统设计与数据模型概览 |
| 3 | `部署与运行说明.md` | 环境要求、本地启动、端口、测试账号、常见问题 |
| 4 | `APIs/current-project-api.md` | 当前后端业务接口与 AI 服务接口总览 |
| 5 | `用户使用手册/常见问题解答（FAQ）.md` | 用户侧功能说明与常见问题 |

若需要查看完整需求、概要设计或测试报告，可阅读：

| 文档/目录 | 说明 |
|---|---|
| `requirements/` | 需求规格说明 LaTeX 源文件 |
| `overview-design/` | 概要设计说明 LaTeX 源文件 |
| `test/` | 测试报告 LaTeX 源文件 |
| `验收自检清单.md` | 交付验收自检表 |

## 3. 文档取舍说明

- `过程/` 中的内容仅用于追溯开发过程，不作为课程组验收时的功能或接口依据。
- 当前平台功能以 `平台功能与设计说明.md`、`APIs/current-project-api.md` 和代码实现为准。
- 后端目录中的 `代码/后端/后端代码/API文档.md` 已重新生成为正式 API 摘要，可直接作为接口交付材料之一。

## 4. 当前平台边界

本项目当前已经实现并文档化的能力包括：

- 用户注册、登录、登出、密码重置、个人资料维护。
- 发布者、审稿人、管理员三类角色的权限与路由隔离。
- 图像/压缩包/PDF 上传，PDF 图片提取，图像检测任务提交、结果查询和报告下载。
- 论文 PDF 预处理、论文 AIGC 检测和学术资源规范性检查任务。
- Review 文本检测，支持在线文本和 `.txt` 文件。
- 人工审核闭环：发布者发起、管理员审批、审稿人复核、发布者查看汇总。
- 组织申请、组织管理、邀请码、检测额度管理。
- 通知、日志、反馈、举报、综合鉴伪报告、检测模型配置和管理端统计。
- AI 服务提供图像检测主链路，并保留论文/Review 文本检测扩展接口。

## 5. 文档维护原则

面向课程组的最终文档应简洁、统一、可验证：

- 不在最终文档中保留“迁移说明”“旧版接口”“任务完成记录”等过程性内容。
- 同类内容优先合并，例如部署、启动、数据库和测试账号合并到 `部署与运行说明.md`。
- 接口路径必须明确是否带 `/api/` 前缀。
- 功能描述必须与当前代码中的路由、模型和前端页面保持一致。
