# AI 学术鉴伪系统

本项目是面向学术内容诚信治理的课程项目，提供学术材料自动检测、专家人工复核、组织与用户管理、审计统计和报告生成能力。系统由用户端前端、管理端前端、Django 后端和 AI HTTP 服务组成。

## 1. 核心功能

| 功能 | 说明 |
|---|---|
| 用户与权限 | 支持发布者、审稿人、管理员三类角色，基于 JWT 认证和角色隔离 |
| 图像鉴伪 | 支持图片、PDF 提取图片、压缩包内图片检测，输出真假判断、置信度、子方法结果和报告 |
| 论文检测 | 支持 PDF 上传、文本提取、清洗分段、论文 AIGC 检测和学术资源规范性检查 |
| Review 检测 | 支持在线文本或 `.txt` 文件，对评审意见文本进行自动检测 |
| 人工审核 | 发布者发起申请，管理员审批，审稿人复核，发布者查看汇总与报告 |
| 组织管理 | 支持组织申请、直接创建、邀请码、组织资料、权限与额度管理 |
| 管理端治理 | 支持用户、资源、任务、审核申请、日志、通知、举报、模型配置和统计看板 |
| AI 服务 | 提供独立 HTTP 服务，支持图像检测主链路和文本检测扩展入口 |

## 2. 项目结构

| 模块 | 路径 | 说明 |
|---|---|---|
| 用户端前端 | `代码/前端/前端用户端` | 发布者和审稿人使用 |
| 管理端前端 | `代码/前端/前端管理端` | 管理员使用 |
| Django 后端 | `代码/后端/后端代码` | 业务 API、认证、任务、资源、报告、日志 |
| AI 服务 | `代码/AI服务/AI服务器代码` | 检测服务、模型注册表、最小可运行模型 |
| 启动脚本 | `scripts` | Windows 本地启动和停止脚本 |
| 交付文档 | `文档` | 面向课程组的最终文档和过程资料 |

```text
文档/过程/
```

## 4. 快速启动

Windows 本地开发推荐在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-local-windows.ps1
```

停止服务：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/stop-local-windows.ps1
```

默认访问地址：

| 服务 | 地址 |
|---|---|
| 用户端前端 | `http://127.0.0.1:3000` |
| 管理端前端 | `http://127.0.0.1:3001` |
| Django 后端 | `http://127.0.0.1:8000` |
| Django API | `http://127.0.0.1:8000/api/` |
| AI 健康检查 | `http://127.0.0.1:8010/health` |

更完整的手动启动流程见 `文档/部署与运行说明.md`。

## 5. 环境基线

| 环境 | 建议版本 |
|---|---|
| Python | 3.11 或 3.12 |
| Django | 4.2 系列 |
| Node.js | 20+ |
| Redis | 6+ 或 7+ |
| 数据库 | 本地 sqlite；云端可使用 MySQL/MariaDB |

后端依赖以 `代码/后端/后端代码/requirements.local.txt` 为准。

## 6. 当前实现边界

- 前端统一调用 Django `/api/`，不直接调用 AI 服务。
- 论文检测当前支持 PDF，不支持 DOCX 直传作为论文检测输入。
- Review 检测支持在线文本或 `.txt` 文件。
- 图像检测是当前 AI 主链路；论文和 Review 检测具备预处理、任务状态、结果查询和报告承载能力。
